# ISV.M — сайт танцевального проекта

Лендинг, онлайн-запись на классы High Heels, календарь интенсивов и материалы для учениц. Админ-панель — по адресу `/admin`.

- `public/` — сайт (основа — HTML5 Boilerplate; GSAP, Swiper, шрифты Fontsource).
- `netlify/functions/` — серверная часть: запись, контент, вход в админку (Netlify Functions + Netlify Blobs).
- `scripts/build.mjs` — сборка: библиотеки + аватар и свежие работы из канала @isvmdance.

## Админка
Первый введённый логин и пароль становятся единственными. Вход возможен максимум с 2 устройств; освободить место можно, отвязав устройство в разделе «Доступ».
Админка и запись в базу работают там, где есть серверные функции (Netlify). На GitHub Pages сайт работает в статическом режиме: заявки отправляются менеджеру в Telegram.
